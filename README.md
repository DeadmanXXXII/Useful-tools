## 🛠️ Useful Pentesting Tools: An Extended List

This document provides an extended and refined list of tools categorized by their primary use in penetration testing. The goal is to offer a comprehensive resource that can continue to be expanded.

***

### 1. 🔍 Information Gathering and OSINT

These tools are crucial for the initial reconnaissance phase, gathering publicly available information about a target.

* **TheHarvester**: Gathers emails, subdomains, hosts, employee names, open ports, and banners from public sources.
* **SpiderFoot**: An automated OSINT tool that integrates with various data sources to collect information about IP addresses, domains, hostnames, and more.
* **Recon-ng**: A full-featured reconnaissance framework designed with modules, similar to Metasploit, for automating OSINT tasks.
* **Maltego**: A graphical link analysis tool used for gathering and connecting information for forensic analysis and OSINT.
* **Sherlock**: A Python script to find social media accounts by username across many platforms.
* **OSINT Framework**: A web-based collection of OSINT tools and resources, categorized for easy navigation.
* **Datasploit**: An OSINT framework to automate the extraction of insights from various online sources.
* **Pipl**: A search engine specializing in finding people's contact, social, and demographic information.
* **Shodan**: A search engine for Internet-connected devices, allowing you to discover devices exposed to the internet.
* **Censys**: Similar to Shodan, it provides a search engine for hosts and certificates on the internet.
* **Google Dorks (Google Hacking Database - GHDB)**: Utilizes advanced Google search operators to find sensitive information exposed on websites.
* **Whois**: A query and response protocol widely used for querying databases that store the registered users or assignees of an Internet resource.
* **Netcraft**: Provides internet security services, including site reports that reveal technology, hosting, and other details about a website.
* **EmailHunter (Hunter.io)**: Helps find email addresses associated with a domain.
* **Have I Been Pwned**: Allows users to check if their email address or phone number has been compromised in a data breach.
* **Robtex**: A tool for investigating IP addresses, domain names, and AS numbers, revealing complex relationships.
* **Panguin Tool**: Helps analyze the impact of Google algorithm updates on website traffic.
* **BuiltWith**: A web profiler tool that reveals what technologies a website is built with.
* **VirusTotal**: A service that analyzes suspicious files and URLs to detect types of malware and automatically shares them with the security community.
* **FOCA (Fingerprinting Organizations with Collected Archives)**: Automatically analyzes metadata from documents and files.
* **Sublist3r**: A Python tool designed to enumerate website subdomains using various search engines and services.
* **Amass**: A powerful and versatile tool for network mapping and attack surface reduction, particularly useful for subdomain enumeration and active reconnaissance.
* **Wayback Machine**: An archive of the internet, allowing you to view how websites looked in the past.
* **DNSDumpster**: A free domain research tool that can discover hosts related to a domain.
* **Maltego CE**: The community edition of Maltego, offering core functionality for intelligence gathering.
* **LinkedIn Scraper**: Custom scripts or tools designed to extract public information from LinkedIn profiles.
* **ReconDog**: A tool for reconnaissance on various targets, including IP addresses, domains, and phone numbers.
* **S3Scanner**: A tool to find and enumerate Amazon S3 buckets.
* **Waybackurls**: Extracts all unique URLs from Wayback Machine for a given domain.
* **Aquatone**: A tool for visual inspection of websites across a large number of hosts and for quickly identifying common web vulnerabilities.
* **Metagoofil**: Extracts metadata from public documents (pdf, doc, xls, ppt, docx, pptx, xlsx) belonging to a target company.
* **Findomain**: A fast domain enumeration tool, often faster than others.
* **Shodan CLI**: Command-line interface for interacting with Shodan.
* **Censys CLI**: Command-line interface for interacting with Censys.
* **DuckDuckGo Scraper**: Scripts or tools to automate searching and extracting information from DuckDuckGo.
* **Scrapy**: An open-source web crawling framework for Python.
* **WPScan**: A black box WordPress vulnerability scanner.
* **Curl**: A command-line tool for transferring data with URLs, essential for interacting with web services.
* **TorCurl**: Curl configured to route traffic through the Tor network for anonymity.
* **FOFA**: A Chinese-based alternative to Shodan for asset search.
* **BinaryEdge**: For internet-wide asset search and exposure analysis.
* **GitRob**: Scans GitHub organizations for sensitive data exposure.
* **GitLeaks**: Scans git repositories for secrets and sensitive information.
* **Emailrep.io**: Provides reputation checks for email addresses.
* **ExifTool**: A free, open-source program for reading, writing, and editing meta information in a wide variety of files.

### 2. 📡 Network Scanning

These tools are used to identify live hosts, open ports, and services running on a network.

* **Nmap (Network Mapper)**: A powerful open-source tool for network discovery and security auditing.
* **Netcat**: A versatile networking utility for reading from and writing to network connections using TCP or UDP. Often called the "TCP/IP swiss army knife."
* **Tcpdump**: A common command-line packet analyzer.
* **Wireshark**: A widely used network protocol analyzer for capturing and interactively Browse the traffic running on a computer network.
* **Angry IP Scanner**: A fast and friendly network scanner for discovering hosts and ports.
* **ZMap**: A fast single-packet network scanner.
* **Masscan**: A very fast network port scanner, capable of scanning the entire Internet in under 6 minutes.
* **Unicornscan**: A lightweight and efficient network scanner, often used for quickly identifying active services.
* **Hping3**: A network tool able to send custom TCP/IP packets and display target replies like ping.
* **Nmap Scripting Engine (NSE)**: A powerful feature of Nmap that allows users to write (and share) simple scripts to automate a wide variety of networking tasks.
* **Fing**: A network scanner for discovering devices connected to a network.
* **Netdiscover**: An active/passive ARP reconnaissance tool.
* **EtherApe**: A graphical network monitor.
* **LanSweeper**: An agentless network inventory, asset management, and software deployment solution.
* **Netstat**: A command-line utility for displaying network connections, routing tables, interface statistics, etc.
* **P0f**: A passive OS fingerprinting tool.
* **NetworkMiner**: A forensic analysis tool for Windows that can extract artifacts from network traffic.
* **Netwag**: A GUI for Netcat.
* **Socat**: A versatile relay for bidirectional data transfer between two independent data channels.
* **PacketCapture**: Generic term for tools that capture network packets.
* **ARP Spoofing Tools (e.g., Ettercap)**: Tools used to perform ARP spoofing attacks to intercept network traffic.
* **Xplico**: A network forensic analysis tool (NFAT) that extracts data from internet traffic.
* **Kismet**: A wireless network detector, sniffer, and intrusion detection system.
* **Nping**: An Nmap tool for network packet generation and response analysis.
* **Tcpflow**: Captures data flowing between two specified IP addresses or ports and stores it in a file.
* **Tshark**: The command-line version of Wireshark.
* **RustScan**: An extremely fast port scanner, designed for speed.
* **Amass active enumeration**: While also an OSINT tool, Amass can perform active DNS enumeration.

### 3. 🛡️ Vulnerability Scanning

These tools identify known vulnerabilities in systems, applications, and networks.

* **Nessus**: A popular proprietary vulnerability scanner.
* **OpenVAS (Greenbone Vulnerability Management - GVM)**: An open-source vulnerability scanner derived from Nessus.
* **Nikto**: A web server scanner that performs comprehensive tests against web servers for multiple items, including over 6700 potentially dangerous files/CGIs.
* **Nexpose**: A vulnerability management solution by Rapid7.
* **Qualys**: A cloud-based suite of security and compliance solutions, including vulnerability management.
* **Arachni**: A high-performance, Ruby-based web application security scanner.
* **W3AF (Web Application Attack and Audit Framework)**: A framework for identifying and exploiting web application vulnerabilities.
* **Burp Suite Scanner**: The automated vulnerability scanning component of Burp Suite Professional.
* **Retina**: A vulnerability management solution.
* **Rapid7 InsightVM**: A vulnerability management solution that integrates with Nexpose.
* **Vuls**: An open-source vulnerability scanner for Linux/FreeBSD/container/middleware.
* **Clair**: An open-source project for static analysis of container images for security vulnerabilities.
* **Trivy**: A simple and comprehensive vulnerability scanner for containers and other artifacts.
* **OWASP Dependency-Check**: Analyzes project dependencies and determines if there are any known, publicly disclosed vulnerabilities.
* **Prowler**: A command-line tool that helps you with AWS security best practices assessments, auditing, hardening, and incident response.
* **ScoutSuite**: An open-source multi-cloud security auditing tool that enables security posture assessment of cloud environments.
* **CloudSploit**: An open-source project to scan cloud accounts for security risks.
* **Kube-Bench**: Checks whether Kubernetes is deployed securely by running the checks documented in the CIS Kubernetes Benchmark.
* **Kube-Hunter**: Hunts for security weaknesses in Kubernetes clusters.
* **Lynis**: A security auditing tool for Linux, macOS, and Unix-based systems.
* **GVM (Greenbone Vulnerability Management)**: The full framework including OpenVAS.
* **Gf (Golang Fuzzing Tool)**: A tool for fuzzing web applications.
* **Vulners**: A vulnerability database and scanner.
* **XSSStrike**: An advanced XSS detection suite.
* **Gato**: A tool for discovering known vulnerabilities.
* **WAFW00F**: Identifies and fingerprints Web Application Firewall (WAF) products.
* **S3Scanner**: A tool to find and enumerate Amazon S3 buckets (also useful for misconfigurations).
* **VIDAR**: A tool for extracting credentials from various applications.
* **Scanless**: A simple tool to use sites like urlscan.io, centralops.net, etc., to perform scans.
* **Nessus CLI**: Command-line interface for Nessus.
* **OpenVAS CLI**: Command-line interface for OpenVAS.
* **Vulnscan**: A generic term for a vulnerability scanner, often referring to custom scripts or less common tools.
* **Nuclei**: A fast and customizable vulnerability scanner based on simple YAML-based templates.
* **SSLscan**: Tests SSL/TLS enabled services to discover supported cipher suites, protocols, and vulnerabilities.
* **OpenSSL**: A cryptography toolkit implementing the SSL/TLS protocols and various cryptographic algorithms.
* **LinScan**: An advanced Linux vulnerability scanner.
* **GVM CLI**: Command-line interface for Greenbone/OpenVAS.
* **CloudMapper**: An AWS security assessment tool.

### 4. 🌐 Web Application Scanning

Specialized tools for discovering vulnerabilities in web applications.

* **Burp Suite**: A leading platform for performing security testing of web applications. Includes an intercepting proxy, scanner, intruder, repeater, and more.
* **OWASP ZAP (Zed Attack Proxy)**: A popular open-source web application security scanner.
* **W3AF**: A framework for identifying and exploiting web application vulnerabilities.
* **Arachni**: A high-performance, Ruby-based web application security scanner.
* **SQLMap**: An open-source penetration testing tool that automates the process of detecting and exploiting SQL injection flaws.
* **Skipfish**: An active web application security reconnaissance tool.
* **NetSparker (Invicti)**: A proprietary web application security scanner.
* **Acunetix**: A proprietary web vulnerability scanner.
* **XSSer**: An automated framework to detect and exploit XSS vulnerabilities.
* **WebInspect**: A proprietary web application security scanner by Micro Focus.
* **Nikto**: A web server scanner (also listed under general vulnerability scanning, as it can be used for both).
* **DirBuster**: A multi-threaded Java application designed to brute force directories and file names on web and application servers.
* **Dirsearch**: A command-line tool designed to brute force directories and files in websites.
* **Gobuster**: A tool used to brute-force URIs (directories and files) in websites, DNS subdomains, and S3 buckets.
* **WhatWeb**: Identifies websites, including their web servers, analytics, JavaScript libraries, and more.
* **Wappalyzer**: A browser extension that reveals the technologies used on websites.
* **OpenBugBounty**: A platform for crowdsourced web vulnerability research.
* **Fuzzer**: A generic term for tools that feed invalid, unexpected, or random data to computer software to discover coding errors and security loopholes.
* **XSSStrike**: An advanced XSS detection suite.
* **WAFW00F**: Identifies and fingerprints Web Application Firewall (WAF) products.
* **Hail Mary**: A tool that combines multiple web scanners and tools for comprehensive analysis.
* **TestSSL**: A command-line tool that checks the SSL/TLS configuration of a given target.
* **OWASP Amass**: Can also be used for web application subdomain enumeration.
* **WebScarab**: An OWASP project for analyzing web application security.
* **SpiderPig**: A tool for web application security.
* **FFUF**: A very fast fuzzer for web applications (directories, parameters, vhosts).
* **ParamSpider**: Discovers hidden GET and POST parameters.
* **Cariddi**: A passive scan and discovery tool for vulnerabilities in URLs.

### 5. 💥 Exploitation

These tools are used to actively exploit identified vulnerabilities and gain access to systems.

* **Metasploit Framework**: A powerful open-source penetration testing framework with a vast array of exploits, payloads, and post-exploitation modules.
* **Cobalt Strike**: A proprietary red team framework for adversary simulations and advanced persistent threats.
* **Empire (PowerShell Empire)**: A post-exploitation framework written in PowerShell and Python, allowing for rapid deployment of agents.
* **Pupy**: An open-source, cross-platform (Windows, Linux, OSX, Android) remote administration and post-exploitation tool.
* **Koadic**: A Windows post-exploitation rootkit written in Python.
* **AhMyth**: A simple Android Remote Administration Tool (RAT) created using a NodeJS (Express.js) for the server-side, and an Electron framework for the client-side.
* **Frida**: A dynamic instrumentation toolkit for developers, reverse-engineers, and security researchers.
* **BeEF (Browser Exploitation Framework)**: A powerful tool that focuses on the web browser as a primary attack vector.
* **Social-Engineer Toolkit (SET)**: An open-source penetration testing framework designed for social engineering.
* **Veil-Framework**: A collection of tools for generating Metasploit payloads that bypass common antivirus solutions.
* **PayloadsAllTheThings**: A GitHub repository containing various payloads and techniques for different types of attacks.
* **Armitage**: A graphical cyber attack management tool for Metasploit.
* **Msfvenom**: A command-line instance of Metasploit used to generate payloads.
* **Netcat**: Can be used for simple exploitation (e.g., shell listener).
* **ExploitDB**: An archive of exploits and vulnerable software.
* **Ncat**: An enhanced version of Netcat.
* **Binwalk**: A tool for analyzing, reverse engineering, and extracting files from firmware images.
* **Ettercap**: A comprehensive suite for man-in-the-middle attacks.
* **Responder**: A LLMNR, NBT-NS, and mDNS poisoner and rogue authentication server.
* **Setoolkit**: The Social-Engineer Toolkit.
* **Kismet**: While primarily for network sniffing, can be used to gather info for wireless exploitation.
* **NTLMRelayx**: A tool for NTLM relay attacks.
* **SMBExec**: A tool for executing commands over SMB.
* **CrackMapExec**: A post-exploitation tool that helps automate assessing the security of large Active Directory networks.
* **JuicyPotato**: A Windows Local Privilege Escalation from SeImpersonate or SeAssignPrimaryToken privileges.
* **BadPotato**: A variation of JuicyPotato for privilege escalation.
* **Evil-WinRM**: A WinRM shell for pentesters and red teamers.
* **Mimikatz**: A tool for extracting credentials from Windows memory.
* **BloodHound**: Maps out relationships in an Active Directory environment to identify privilege escalation paths.
* **Sliver**: A modern open-source C2 framework written in Golang.
* **Mythic**: A flexible C2 framework for red teaming.
* **Chisel**: A fast TCP/UDP tunnel over HTTP, useful for pivoting.
* **Merlin**: A cross-platform post-exploitation HTTP/2 agent written in Golang.
* **Pwncat**: A sophisticated `netcat` replacement for privilege escalation and post-exploitation automation.

### 6. 🔓 Post-Exploitation

Tools and techniques used after gaining initial access to maintain persistence, collect data, and move laterally.

* **Mimikatz**: Extracts plaintext passwords, hash, PIN codes, and Kerberos tickets from memory.
* **BloodHound**: Visualizes privilege escalation paths in Active Directory.
* **PowerSploit**: A collection of PowerShell modules for post-exploitation tasks, including reconnaissance, privilege escalation, and evasion.
* **Powershell Empire**: A post-exploitation framework (also listed under Exploitation, as it bridges both phases).
* **Windows Credential Editor (WCE)**: A tool to enumerate logon sessions and extract NTLM, Kerberos, or plaintext passwords.
* **Impacket**: A collection of Python classes for working with network protocols, enabling various post-exploitation techniques.
* **CrackMapExec**: A post-exploitation tool that helps automate assessing the security of large Active Directory networks.
* **SharpHound**: The data collector for BloodHound.
* **Evil-WinRM**: A WinRM shell for pentesters and red teamers.
* **FuzzBunch**: A collection of NSA-developed exploitation tools (e.g., EternalBlue, EternalRomance).
* **Responder**: A LLMNR, NBT-NS, and mDNS poisoner and rogue authentication server.
* **SMBRelay**: Tools for performing SMB Relay attacks.
* **Cobalt Strike Beacon**: The agent deployed by Cobalt Strike for command and control and post-exploitation.
* **Post-Exploitation Tools (e.g., PowerView, PowerUp)**: Generic term for various scripts and executables for reconnaissance and privilege escalation within compromised systems.
* **Jupyter Notebook for Data Analysis**: Useful for analyzing collected data during post-exploitation.
* **Metasploit Post-Exploitation**: Modules within Metasploit for tasks like privilege escalation, pivoting, and data exfiltration.
* **Kerberoast**: A technique used to retrieve service principal name (SPN) tickets from Active Directory, which can then be cracked offline.
* **PsExec**: A Sysinternals tool that allows you to execute processes on other systems.
* **Invoke-Phant0m**: A PowerShell script that allows an attacker to disable event logging in a stealthy manner.
* **Seatbelt**: A C# project that performs a number of security-oriented checks on a Windows system.
* **LaZagne**: An open-source application to retrieve passwords from many softwares.
SharpUp: A C# tool to perform privilege escalation checks on Windows.

Rubeus: A C# toolset for raw Kerberos interaction and abuse.

7. 📈 Privilege Escalation
Tools and techniques focused on increasing access rights within a compromised system.

Privilege Escalation Tools (e.g., WinPEAS, Linux Exploit Suggester): General category for tools designed to find and exploit misconfigurations or vulnerabilities for privilege escalation.

PowerSploit: Includes modules like PowerUp for Windows privilege escalation.

LinPEAS (Linux Privilege Escalation Awesome Script): A script to enumerate Linux system information for potential privilege escalation vectors.

WinPEAS (Windows Privilege Escalation Awesome Script): A script to enumerate Windows system information for potential privilege escalation vectors.

Kernel Exploits (e.g., Dirty COW): Specific vulnerabilities in the operating system kernel that can be exploited for privilege escalation.

Sudo Permissions Enumeration: Techniques and tools to identify misconfigured sudo permissions that can lead to privilege escalation.

Linux Exploit Suggester: A script that analyzes system information to suggest potential Linux kernel exploits.

Privilege Escalation Awesome List: A curated list of resources and tools for privilege escalation.

Enum4linux: A tool for enumerating data from Windows and Samba hosts.

LinEnum: A shell script for enumerating Linux system information.

Sudo-Kill: A tool to exploit misconfigured sudo policies.

Windows Exploit Suggester: A Python script that analyzes system information to suggest potential Windows kernel exploits.

Privilege Escalation Cheat Sheet: Reference guides for common privilege escalation techniques.

PEASS-ng: A consolidated suite that includes both LinPEAS and WinPEAS for comprehensive privilege escalation checks.

GTFOBins: A curated list of Unix binaries that can be exploited by an attacker to bypass local security restrictions.

LOLbas (Living Off The Land Binaries and Scripts): A project documenting Windows binaries and scripts that can be used by attackers to bypass security controls.

BeRoot: A post-exploitation tool to check for common privilege escalation vectors on Windows, Linux, and Mac.

8. 📝 Reporting
Tools and methodologies for documenting findings and generating professional reports.

SecLists: A collection of common wordlists used for enumeration and brute-forcing. (While also used in other phases, its output is often directly relevant for reporting attack vectors).

PayloadsAllTheThings: (Also listed under exploitation, as it's a resource for crafting custom payloads, which are then documented in reports).

Rockyou.txt: A very large wordlist commonly used for password cracking.

FuzzDB: A database of patterns and primitives used in fuzzing.

XSS Cheat Sheet: Reference for various XSS payloads.

CVE List: A database of publicly disclosed cybersecurity vulnerabilities.

Dradis Framework: An open-source web-based collaboration and reporting framework for security engagements.

Faraday: A multi-user penetration test IDE for security audits.

Serpico: A simple, open-source report generation tool.

ReportGenerator: A generic term for tools that generate reports from various data sources.

Metasploit Pro Reporting: The reporting capabilities of Metasploit Pro.

Nexpose Report: Reporting features within the Nexpose vulnerability management solution.

PhishTool: A tool for analyzing and reporting on phishing campaigns.

Safety: A Python tool for checking installed package dependencies for known security vulnerabilities.

CherryTree: A hierarchical note-taking application, useful for organizing pentest notes and findings.

OWASP ZAP Report Generation: Features within OWASP ZAP for creating reports.

Burp Suite Report Generator: Features within Burp Suite for creating reports.

Threat Dragon: An open-source threat modeling tool.

Scribe: A generic term for tools that help in writing and documentation.

ReportLab: A Python library for creating PDF documents.

Trello or Jira: Project management and issue tracking tools that can be adapted for collaborative reporting of findings.

Obsidian: A powerful knowledge base that works on local Markdown files, excellent for building a personal pentesting knowledge base.

Hacktricks: An extensive and well-regarded online resource for penetration testing cheat sheets and methodologies, invaluable for consistent reporting.

9. 🧹 Post-Test Clean-Up
Ensuring that no remnants of the penetration test are left on the target systems.

Ensure no backdoors or test files are left on the systems: Manual verification is key here.

Remove any tools or artifacts used during the test: This includes scripts, executables, and temporary files.

Use tools like CCleaner or BleachBit to clean up traces if necessary: For general system cleaning, though specific forensic tools are often preferred in a pentesting context.

Data Wipe Utilities (e.g., DBAN): For securely erasing data from disks.

Log Cleaning Tools (e.g., Logrotate, LogCleaner): For managing and clearing system logs.

Forensic Clean-Up Tools (e.g., SDelete, Eraser): For securely deleting files and overwriting free space.

Post-Test Report Cleanup: Ensuring all sensitive information is removed from reports before sharing with the client.

Final System Verification Tools: Tools or procedures to ensure the system's integrity after cleanup.

Disk Wipe Utilities: Tools designed to securely erase data from storage devices.
